TEXLAB KONVEKSI — PREMIUM WEBSITE

FILES:
- index.html: halaman utama company profile
- katalog.html: halaman katalog dan galeri portofolio
- assets/: foto dan logo yang dipakai website

CARA MEMBUKA:
1. Ekstrak ZIP.
2. Buka folder texlab_premium_site.
3. Klik dua kali index.html.
4. Klik "Lihat Semua Portofolio" untuk membuka katalog.html.

KONTAK:
Tombol kontak mengarah ke https://wa.me/6281262151122

CARA MENGUBAH KONTEN:
- Teks: buka index.html atau katalog.html dengan editor teks (misalnya Notepad atau VS Code), cari kalimat yang ingin diubah, lalu ganti.
- Foto: ganti file di folder assets dengan foto baru menggunakan nama file yang sama agar otomatis terpakai. Simpan salinan cadangan terlebih dahulu.
- Tambah foto portofolio: salin foto baru ke assets, lalu duplikasi satu blok <a class="card"> di katalog.html dan ubah nama file, judul, serta deskripsinya.
- Untuk publikasi, unggah seluruh folder beserta folder assets ke hosting; jangan hanya mengunggah index.html.
